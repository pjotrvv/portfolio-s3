# Peer review: DGT
### 28/11/2025

---

## User story:
### Goed:
- Acceptatiecriteria zijn bijna allemaal meetbaar en duidelijk.
- Gherking scenarios zijn over het algemeen goed gemaakt. 
- Branch/pull-request is gelinked aan user story, erg handig voor overzichterlijkheid.
- Defenition of done ziet er goed en duidelijk uit.

### Tips:
- User story zit alleen in de titel, voor overzicht zou deze in de markdown zelf kunnen en dan kan de titel kort en eenvoudig blijven.
- User story is niet echt een user story, aangezien het begint met "Als developer". Een developer is eigenlijk geen gebruiker.
- De user story is ook deels een learning story: Het eerste gedeelte is een learning story, en het tweede gedeelte is een normale user story. Dit had beter opgesplitst kunnen worden.
- De laatste acceptatiecriteria is een klein beetje vaag: wat betekent "correct"? Is dit correct volgens wat de frontend wilt ontvangen of correct json gebruik.
- User story mist defenition of ready.
- Bij de eerste gherkin scenario is het niet helemaal duidelijk wat "alle vereiste velden" zijn.
